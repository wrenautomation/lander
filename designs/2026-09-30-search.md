# Search and AI answers (SEO + GEO)

Living doc. How wrenautomation.com gets found by Google, Bing and AI answer engines, and what runs on its own.

## What is set up

- **Search Console**: domain property `sc-domain:wrenautomation.com`. Owners: william@wrenautomation.com and the
  `wren-sender` service account (verified by DNS TXT, added through the Site Verification API). Sitemap submitted.
  The service account reads it by API; no browser needed after setup.
- **Structured data** (`src/lib/structured-data.ts`, emitted by `Head.astro`): Organization, founder, WebSite and
  WebPage on every indexed page. FAQPage where the page has questions. The services the page sells as offers. Built
  from the content files, no prices.
- **llms.txt** (`src/pages/llms.txt.ts`): the site in Markdown for AI assistants, from the same content files.
  Figures keep their source links.
- **IndexNow** (`scripts/indexnow.mjs`, run in CI): pages whose words changed go to Bing and the other IndexNow
  engines right after each deploy. Key file: `public/<key>.txt`.
- **One host**: www 301s to the apex (`workers/www-to-apex`). pages.dev copies send `X-Robots-Tag: noindex`
  (`public/_headers`). Noindex pages (404) carry no canonical.
- AI crawlers (GPTBot, ClaudeBot, PerplexityBot, OAI-SearchBot) get 200; robots.txt allows everything but `/api/`.

## State on 2026-09-30

- Indexed: `/`, `/privacy`. Discovered, not yet crawled: `/recruiting/lead-reactivation`, `/agencies`. `/terms`
  unknown until the sitemap is read. No search impressions yet.

## Decisions

| # | Decision | Why |
|---|---|---|
| S1 | Search Console through the service account, not a browser login | The loop in wren reads it from Lambda with the key it already has. |
| S2 | IndexNow only for pages whose words changed | The engines ask for that; resubmitting every page on every push gets ignored. |
| S3 | Titles lead with what someone would type, then " \| Wren Automation" | The page's topic is what ranks; the brand is known to few yet. |
| S4 | Changes to copy from the keyword loop come as a pull request, never straight to main | A push to main is a deploy, and the copy is William's. |
| S5 | Only live, verified profiles in `site.yaml` `profiles` | A wrong sameAs ties Wren to someone else's account. X and TikTok wait until their handles are confirmed. |
