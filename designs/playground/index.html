Government of Canada

Document pipeline · 2025

Before

Four people, one shared spreadsheet, and a template that broke whenever a column was renamed. Six to seven hours a week of retyping.

Day to day now

Someone fills one form. Six minutes later five documents are in the shared drive, named and formatted. If a detail changes, they edit the sheet and only the affected documents re-render. Nobody opens a template.

Two human steps, submit and send. Everything between them runs itself.

a person does thisruns on its own
  1. Fill one form

    Required fields are enforced at entry. The shared spreadsheet is gone.

  2. Store

    One source-of-truth sheet, version history on every edit.

  3. Render

    Five templates fill from the sheet on submit, in the department's own format.

  4. Catch edits

    A scheduled job spots later changes and re-renders only what changed.

  5. Send

    Five documents, named and filed in the shared drive, ready to go.

Test data to report · 2025

Before

Instrument exports copied by hand into a weekly report. Plots rebuilt in Excel each time. Half a day, every week, by the most senior person.

Day to day now

Tests run as they always did. The report is waiting on Monday morning with the plots already in the group's style. The only thing anyone reads closely is the short list of runs the checks flagged.

One human step at each end. Everything between the test and Monday morning runs itself.

a person does thisruns on its own
  1. Run the test

    Exports land in the shared folder as before. Nothing changed for the people running tests.

  2. Watch

    A watcher notices new exports within a minute of arrival.

  3. Check

    Each run is validated. Partial or bad runs are flagged, never silently included.

  4. Plot

    Per-run plots generated in the group's existing style.

  5. Compile

    The weekly report assembled in the same format every time, archived by run.

  6. Read on Monday

    Skim the flagged list. That is the whole job now.
